# M50 / Merak：沿用具体配置的目标标识

[README_merak](../../../README_merak.md) 用 M50/天璇描述 Merak 并提及 XH2a/YueHui。
目前主要发布的 [workflow 配置](../../../configs_merak/workflows/xh2a/) 使用 `XH2a`；
不能把产品称呼直接写成 `chip_arch: m50`，也不能从本文推出 M50 与所有 XH2/YH 产品等同。

| 路径 | 当前写法与边界 |
| --- | --- |
| LLM workflow | `export.model.chip_arch: XH2a`，模型类型是 `export.model.model_type` |
| other-model workflow | `export.target_device: XH2a`，模型类型是 `export.model.type` |
| 图表达 | 优先沿用 SDK 算子接口；注意 [attention](../operators/attention.md)、[归一化](../operators/normalization.md) 和 [cache](../structures/cache.md) 的具体语义 |
| 量化 | 以对应 YAML 和节点/算子配置为准，`w16a16_sefp` 不等于未经量化的原生 FP16 |

当前 CI 的四个 [Transformer block 用例](../../../benchmark_test/ci_test_transformer5.16.0/_transformer516_block_export.py)
消费 SHA-256 固定的量化 checkpoint，在给定 XH2a 配置下运行当前导出路径。
它们不在 CI 重跑 AutoRound，不生成 golden；导出通过不能作为 NPU 真机数值或性能通过。

变更 dtype、head 维度、cache 模式或图容量时，需在相应组合上重新取证；
本页没有提供可套用到全部模型的对齐倍数、容量上限或性能承诺。
